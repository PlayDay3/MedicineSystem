# MedicineSystem
这是一个药品管理系统，可以为自己的药店，私人诊所管理自己药品，该系统主要包括以下功能：有属于自己药品库，自由添加修改药品属性，可以动态编写修改处方单，
可以将处方单数据生成Word文档。
## 药品库
在药品库中可以自由添加药品，修改药品属性
- 药品仓库，可用于查看自己仓库药品库存量
![image](https://github.com/user-attachments/assets/d6e19edc-bab0-4715-8440-669a4a17f90a)
- 药品名界面，此界面可以添加新的药品名，并将药品添加到药品库中
![image](https://github.com/user-attachments/assets/8fd388c5-57b3-45b4-85a5-2fcbdb0163f1)
## 处方单
用于用户为病人书写处方单，输入病人信息和需要开的药品就能生成处方单
- 在此界面中可以增删查改用户创建的处方单
![image](https://github.com/user-attachments/assets/8368ba4d-af43-4bf4-837d-aef4865f2a79)
- 在处方单界面中，可以编写病人的信息，以及需要服用的药品信息
![image](https://github.com/user-attachments/assets/ad030d9f-a45b-4c93-a6c8-b795e15fd49c)
-点击保存为Word文档即可生成.doc文档
![image](https://github.com/user-attachments/assets/08d60095-297a-4cda-ac91-06f26d07879d)
